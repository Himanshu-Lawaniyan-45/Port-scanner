# Port Scanner

A simple educational port scanner developed to understand basic networking and cybersecurity concepts.

## Features

* Scan specified TCP ports
* Identify open/closed ports
* Simple command-line interface
* Useful for learning networking fundamentals

## Technologies Used

* Python
* Socket Programming
* Computer Networking

## How to Run

```bash
python port_scanner.py
```

## Ethical Use

This project is intended for educational purposes and authorized testing only. Scan only systems that you own or have explicit permission to test.

## Learning Objectives

* Understanding TCP ports
* Learning socket programming
* Understanding basic network scanning
* Practicing Python programming
